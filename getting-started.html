What CSS actually does

HTML gives your page structure and meaning. CSS describes how that structure should look and how boxes should be arranged. A paragraph is still a paragraph after you style it; CSS simply controls its presentation.

CSS syntax

selector {
property: value;
}

A selector chooses one or more elements. A property names what you want to change. A value says how you want it changed. Each declaration normally ends in a semicolon.

Example

h1 {
color: darkgreen;
font-size: 2.4rem;
}

Values and units

CSS accepts many kinds of values. Common ones include named colours, numbers, lengths and percentages.

Unit/valueTypical useExample
pxFixed-size detailborder: 1px solid
remText and scalable spacingfont-size: 1.2rem
%Size relative to a containing contextwidth: 80%
vw / vhRelative to viewport sizemin-height: 70vh
autoLet the browser calculate a suitable valuemargin: 0 auto

Comments

Comments are ignored by the browser and can help explain why a rule exists.

/* This gives the main article a comfortable reading width. */
.article { max-width: 800px; }

Mini practice

Create a heading and a paragraph. Give the heading a different colour and make the paragraph slightly larger. Then change the paragraph colour without touching the HTML.

Checkpoint: You are ready for selectors when you can explain the difference between a selector, a property and a value.
