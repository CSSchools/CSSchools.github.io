Chapter 6

Responsive CSS

A responsive page adapts to different screens instead of assuming everybody is using the same monitor.

On this pageViewportMobile-firstMedia queriesFluid sizingImagesTesting

The viewport

For an HTML page to behave properly on mobile devices, use the viewport meta element:

<meta name="viewport" content="width=device-width, initial-scale=1">

Mobile-first thinking

A useful approach is to make a sensible narrow-screen layout first, then add changes for wider screens. This avoids treating mobile as an afterthought.

Media queries

.cards {
grid-template-columns: 1fr;
}

@media (min-width: 800px) {
.cards {
grid-template-columns: repeat(3, 1fr);
}
}

The important idea is not the exact breakpoint. Choose a point where the content starts to look cramped, then change the layout there.

Fluid sizing

Relative units and functions can help components flex naturally.

.content {
width: min(100% - 2rem, 70rem);
margin-inline: auto;
}

min(), max() and clamp() can reduce the need for lots of tiny breakpoint changes.

Responsive images

img {
max-width: 100%;
height: auto;
}

This stops an image from becoming wider than its containing element in the common case.

Testing properly

Resize your browser. Test with a narrow window, a medium tablet-like size and a wide desktop. Also test keyboard navigation and zoom. A design that only works at one exact width is not truly responsive.

Practical rule: Let the content decide the breakpoint. Do not build your entire site around a list of popular phone widths.
