Chapter 4

The CSS box model

Nearly every visible HTML element can be understood as a box. Once this clicks, spacing stops feeling like guesswork.

On this pageThe four partsWidth and heightMargin and paddingBox sizingDisplayPractice

The four parts

The classic box model has four layers:

PartWhat it means
ContentThe actual text, image or child content.
PaddingSpace between the content and the border.
BorderThe visible edge surrounding the padding and content.
MarginSpace outside the border, separating this box from others.
Content
Padding sits around this area.
Border surrounds the padding.
Margin sits outside the border.

Width and height

.card {
width: 320px;
min-height: 180px;
}

Setting a fixed width can be fine for a small component, but overly rigid widths can cause problems on narrow screens. max-width is often useful for keeping content readable without making it too wide.

Margin and padding

.box {
padding: 1rem;
margin: 0 auto 2rem;
}

The shorthand can contain one to four values. With four values, the order is top, right, bottom, left.

padding: 10px 20px 30px 40px;

Box sizing

By default, declared width and height describe the content box. With border-box, the declared size includes padding and border. Many modern stylesheets apply it globally because it makes sizing more predictable.

*, *::before, *::after {
box-sizing: border-box;
}

Display values

ValueBasic idea
blockStarts on a new line and normally takes available inline space.
inlineFlows with text and does not behave like a full-width block.
inline-blockFlows inline but allows useful box dimensions.
noneRemoves the element from the normal layout.

Practice

Create two boxes with the same width. Give one generous padding and the other generous margin. Notice how padding changes the space inside the border, while margin changes the space outside it.
