Chapter 5

Layout: Flexbox, Grid and positioning

Layout is where CSS starts to feel powerful. You are no longer just decorating boxes; you are deciding how those boxes work together.

On this pageDisplayFlexboxGridPositioningZ-index

Start with display

For modern layouts, the two most important tools are Flexbox and Grid. Think of Flexbox as a one-dimensional layout system and Grid as a two-dimensional one.

Flexbox

Use Flexbox when you mainly need to arrange items in a row or a column and control alignment and available space.

.nav {
display: flex;
gap: 1rem;
align-items: center;
justify-content: space-between;
}

CSS Grid

Grid is excellent when the page needs rows and columns together, such as card collections, dashboards and broader page structures.

.cards {
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 1rem;
}

Positioning

Normal flow is the browser's default way of placing elements. Positioning lets you alter that behaviour when you have a clear reason.

.badge {
position: absolute;
top: 1rem;
right: 1rem;
}

Common position values are static, relative, absolute, fixed and sticky. An absolutely positioned element is normally positioned relative to its nearest positioned ancestor.

Z-index

z-index influences which positioned elements appear above others within the relevant stacking context.

Do not use positioning as your first layout tool. If you are trying to build columns, use Grid or Flexbox first. Positioning is better for things such as overlays, badges and sticky interface pieces.
