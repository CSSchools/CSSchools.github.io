CSSchools
=========

A basic multi-page CSS tutorial website in plain HTML and CSS.

How to use
----------
Open CSSchools in a browser, or serve the folder with any simple local web server.

The content is original tutorial material informed by:
- https://developer.mozilla.org/en-GB/docs/Web/CSS
- https://www.w3.org/Style/CSS/

No external CSS framework is required.
