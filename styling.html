Chapter 3

Colour, text and visual styling

Once you can target the right elements, CSS becomes a toolbox for typography, colour, borders and backgrounds.

On this pageColourTextFontsBackgroundsBorders and radiusShadows and effects

Colour

CSS colours can be written in several formats. Named colours are easy to read, hexadecimal values are common, and rgb() and hsl() can be useful when you want more control.

.title {
color: #0f7a4b;
}

.subtle {
color: rgb(80 95 88);
}

Text properties

p {
font-size: 1rem;
line-height: 1.7;
text-align: left;
letter-spacing: .01em;
}

Line-height is especially important for reading. A little extra space between lines can make a block of text far easier to follow.

Live-looking example

Good typography does not need to shout. It simply makes the content easier to read.

Fonts and font stacks

You can ask for a preferred font followed by fallbacks. The browser uses the first available option.

body {
font-family: Arial, Helvetica, sans-serif;
}

For a small site, a simple system font stack is often enough. For more polished branding, web fonts can be loaded separately.

Backgrounds

.panel {
background-color: #e8f5ee;
background-image: url("pattern.png");
background-size: cover;
}

A background image is decorative in many cases, so avoid using it as the only way to communicate important information.

Borders and rounded corners

.card {
border: 1px solid #dbe4df;
border-radius: 12px;
}

Shadows and effects

.card:hover {
box-shadow: 0 8px 24px rgb(0 0 0 / .08);
transform: translateY(-2px);
}
Good habit: Visual effects should support the content. A page does not become better just because every card has a giant shadow.
