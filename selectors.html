Chapter 2

Selectors and specificity

Selectors are CSS's way of pointing at HTML. The better you understand them, the less mysterious your stylesheet becomes.

On this pageBasic selectorsClasses and IDsCombining selectorsPseudo-classesSpecificityPractice

Basic selectors

p { color: #333; }
h1 { margin-bottom: 1rem; }
* { box-sizing: border-box; }

The element selector p matches paragraphs. The universal selector * can match every element.

Classes and IDs

A class is normally the main tool for reusable styling.

.note {
background: #e8f5ee;
}

#main-title {
font-size: 3rem;
}

HTML might contain <p class="note"> or <h1 id="main-title">. IDs should generally be unique on a page; classes can be reused.

Combining selectors

article p { max-width: 65ch; }
nav > a { padding: .5rem; }
h2, h3 { line-height: 1.2; }
button:hover { transform: translateY(-1px); }
SelectorMeaning
article pA paragraph anywhere inside an article.
article > pA paragraph that is a direct child of the article.
h2, h3Both headings are selected.
button:hoverA button while the pointer is over it.

Pseudo-classes

Pseudo-classes describe a state or condition rather than a literal element in the HTML. Useful examples include :hover, :focus, :checked and :disabled.

Accessibility tip: Never remove a visible keyboard focus style just to make a design look cleaner. A keyboard user needs to be able to see where focus is.

Specificity, in plain English

When multiple rules match the same element, the browser needs a way to decide which declaration wins. Specificity is one part of that process. In a rough beginner-friendly order, an ID is more specific than a class, and a class is more specific than an element selector.

p { color: black; }
.warning { color: darkred; }
#special { color: navy; }

It is usually better to write simple selectors than to keep adding layers of specificity. A tidy stylesheet is easier to change later.

Practice

Make three paragraphs. Give two of them the same class, then create a rule that styles only the paragraph inside a particular section.
