CSS tutorial

Learn CSS, one piece at a time.

CSS is what turns a plain HTML document into something readable, organised and genuinely pleasant to use. This CSSchools guide starts at the beginning and works towards real page layouts.

Start the tutorial →

What you will learn

CSSchools is laid out like a small wiki. You can work through the pages in order, or jump straight to the subject you need. The examples use normal HTML and CSS, so you can copy them into a basic project and see what changes.

1. Getting started

Understand CSS syntax, rules, declarations and the three main ways to add CSS.

2. Selectors

Learn how CSS chooses which HTML elements to style, including classes, IDs and combinations.

3. Styling

Work with colour, text, fonts, backgrounds, borders and simple visual effects.

4. Box model

Get comfortable with content, padding, borders, margins and box-sizing.

5. Layout

Build useful page structures with display, Flexbox, Grid and positioning.

6. Responsive

Make your pages work properly on phones, tablets and desktop screens.

7. Beyond the basics

Move into the cascade, custom properties, transitions, transforms and tidy CSS habits.

How to use the site

Do not try to memorise every property. Learn the idea first, then use the examples as patterns. CSS is much easier once you can look at a page and think, “That is a box, so I need to control its size, spacing and layout.”

Tip: Keep a tiny index.html and styles.css project open while you learn. Change one value at a time and refresh the page.

A tiny CSS example

p {
color: seagreen;
font-size: 1.1rem;
}

The selector is p. The declarations say which properties to change and what values to use. That basic pattern comes up again and again.
