Chapter 7

Beyond the basics

Now that you understand the fundamentals, a few modern CSS features can make larger stylesheets easier to manage and small interactions feel polished.

On this pageThe cascadeCustom propertiesCalc and clampTransitionsTransformsAnimationsGood CSS habits

The cascade

CSS stands for Cascading Style Sheets because multiple rules can apply to the same element. The browser considers things such as origin, importance, cascade layers, specificity and source order when deciding the winning declaration.

p { color: black; }
p { color: darkgreen; }

When otherwise competing declarations have equal weight and specificity, the later one wins. In practice, aim for predictable selectors rather than fighting the cascade.

Custom properties

Custom properties let you store reusable values, which is particularly handy for colours, spacing and theme choices.

:root {
--brand: #0f7a4b;
--space: 1rem;
}

.button {
background: var(--brand);
padding: var(--space);
}

Calc, min, max and clamp

.title {
font-size: clamp(2rem, 5vw, 4rem);
}

.panel {
width: calc(100% - 2rem);
}

These functions let the browser calculate values rather than forcing you to create a separate rule for every possible screen size.

Transitions

.button {
transition: background-color .2s ease, transform .2s ease;
}
.button:hover {
transform: translateY(-2px);
}

Transforms

Transforms can move, scale, rotate or skew an element without changing the normal flow in the same way that changing layout properties does.

Animations

@keyframes fade-in {
from { opacity: 0; }
to { opacity: 1; }
}

.panel {
animation: fade-in .4s ease;
}

Good CSS habits

  • Use class names that describe purpose or meaning rather than one-off appearance where practical.
  • Keep selectors simple and avoid unnecessary specificity.
  • Group related rules so you can find them later.
  • Use consistent spacing and naming.
  • Prefer layout systems such as Flexbox and Grid over large piles of absolute positioning.
  • Check keyboard focus, readable contrast and narrow-screen behaviour as you build.
You do not need to know all of CSS. Even experienced developers look up properties and browser details. The real skill is knowing which CSS idea solves the problem you have.
